KAMAIKASHI SENSORLESS ESC
Reverse-engineering notes / archive snapshot

==================================================
1. PROJECT TYPE
==================================================

Scooter-class BLDC ESC based on STM32F103C8T6.
Reverse-engineered board with custom firmware bring-up.

Main goals:
- stable bridge control
- true 6PWM
- open-loop startup
- current sensing understanding
- sensorless transition later

==================================================
3. CRITICAL DISCOVERIES
==================================================

A) No confirmed global gate-driver enable
The board appears to have driver supply rails, but no confirmed separate global enable line for the three FD2103S drivers.

B) Safe OFF state is not solved by timer disable alone
Disabling complementary outputs alone caused low-side sticking.

Reliable OFF per phase:
- HIN = LOW
- LIN = HIGH

This must be forced by GPIO for OFF phases.

C) True 6PWM can be used for active phases
Working model:
- active phases -> TIM1 complementary outputs
- OFF phase -> GPIO hard-off

D) Current shunts are only on low-side emitters
This means current measurement is only valid when the corresponding low-side transistor / return path is conducting.

This is sector dependent low-side current sensing, not always-valid full phase current measurement.

==================================================
4. CURRENT SENSE INTERPRETATION
==================================================

Resistor-based tests confirmed:

Step 0 = A+ B- C float
- strongest on IB

Step 2 = B+ C- A float
- strongest on IC

Step 4 = C+ A- B float
- strongest on IA

Conclusion:
- IA corresponds to low-side A return path
- IB corresponds to low-side B return path
- IC corresponds to low-side C return path

==================================================
5. COMMUTATION TABLE
==================================================

Step 0: A+ B- C float
Step 1: A+ C- B float
Step 2: B+ C- A float
Step 3: B+ A- C float
Step 4: C+ A- B float
Step 5: C+ B- A float

==================================================
8. IMPORTANT RULES
==================================================

- Do not trust timer disable alone for OFF phases.
- Use current-limited supply during bring-up.
- Treat low-side shunt readings as sector dependent.
- Keep SWD alive.
- Do not rewrite hardware assumptions without checking on board.
